Schreiben Sie ein Programm, dass eine von via CommnandLine eingelesene ganzzahlige, positive Zahl (Zahlenraum $`\mathbb{Z}^+`$) invertiert. Unter invertieren der Zahl soll verstanden werden, dass die Einerstelle nach der Invertierung die höchste Stelle, die Zehnerstelle die zweithöchste, usw. ist.

Die Ausgabe des Programms sollte wie folgt aussehen:

```
[IN] Geben Sie eine ganze positive Zahl ein: 123456
Invertierte Zahl: 654321
```
